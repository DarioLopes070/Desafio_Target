# Desafio Técnico - Desenvolvedor Júnior

Este repositório contém a solução para o desafio técnico proposto, desenvolvido em **Python**.

## 🚀 Tecnologias Utilizadas
* Python 3.x

## 📋 Funcionalidades Desenvolvidas
1. **Cálculo de Comissão de Vendas:** Processa um conjunto de dados de vendas e calcula a comissão por vendedor aplicando regras progressivas (0%, 1% ou 5%).
2. **Controle de Movimentação de Estoque:** Gerencia entradas e saídas de mercadorias no depósito, gerando IDs únicos, descrições e retornando o saldo final atualizado de forma otimizada.
3. **Cálculo de Juros por Atraso:** Calcula os dias de atraso, o valor dos juros (baseado em taxa diária) e o montante total atualizado com base na data de vencimento e na data atual.
